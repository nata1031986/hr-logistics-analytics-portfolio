## About the data
All datasets are **synthetic** — generated by [`generate_data.py`](generate_data.py) with fixed random seeds, so every number can be reproduced.
Companies, carriers, SKUs, applicants and employees are fictional; US city names are real.
I built in realistic patterns and then found them through analysis. Dollar assumptions (replacement cost, sourcing costs, carrying cost) are marked as assumptions wherever they are used.
